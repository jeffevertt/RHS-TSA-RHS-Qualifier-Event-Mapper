TSA Event → Qualifier Event Mapper

Use this tool to help identify which qualifier events you need to participate in — you have some choice in this. For each TSA event, you'll need to reach at least a 1.0 total weighting across the tests and events tied to it.

A test or event only needs to be done once — it counts toward every TSA event that lists it, so there's no need to sign up for the same one twice. Portfolio Presentation is the one exception: it's specific to each TSA event, since the content is different each time.

For tests, only one teammate needs to take it — if more than one does, the highest score counts for the team.
